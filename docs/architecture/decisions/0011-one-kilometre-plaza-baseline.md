# ADR 0011：首版广场采用一公里版本化网格

- 状态：已接受
- 日期：2026-08-02
- 替代范围：ADR 0009 中的 500 米 staging 边长基线；其余版本化网格与持久化锚点决策继续有效

## 背景

500 米网格完成了真实 iPhone 定位、四广场懒创建、离线缓存和 150 米锚点的技术验证，但首版冷启动用户密度较低。过小网格会过早分散用户和消息，不利于形成可感知的附近交流。

## 决策

1. 首版激活边长为 1000 米的正方形网格版本，主广场加三个相邻广场覆盖约 2 公里乘 2 公里的四格区域。
2. 不修改已经进入共享环境的 500 米版本。数据库通过前向迁移将版本 1 退役并激活版本 2；用户下一次刷新地理上下文时自动建立版本 2 锚点。
3. 150 米锚点、连续定位确认和停留时间策略暂不随网格边长变化，继续通过真实道路测试调参。
4. 网格边长仍是服务端版本数据，不写死在移动端。未来高密度常住区域可新增 500 米或 250 米版本，低密度区域可新增更大版本。
5. 演唱会、体育场等临时或边界明确的场景使用独立活动或场馆覆盖层，不因短时人流自动拆分基础广场。

## 影响

- 旧广场会话和消息不删除，但退役版本不再由新的地理上下文返回。
- 网格版本切换会生成新的广场 ID 与会话，必须在正式运营前完成，避免用户感知到无意义换群。
- 展示名称与网格 ID 分离。当前中性名称只是技术兜底，后续由高德稳定地标命名适配器替换，不能把坐标或内部网格编号直接展示给用户。
