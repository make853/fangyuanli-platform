# ADR 0018：统一聊天输入区域状态机

## 状态

已采纳。

## 背景

系统键盘由 iOS 异步控制，自定义表情和附件面板由 Flutter 布局控制。如果两者分别增删高度，键盘切换面板时会短暂双重占位，反向切换时会出现高度空档，导致聊天页面跳动、最后一条消息位移和顶栏视觉状态泄漏。

广场、地点、活动和好友私聊都需要同一套输入能力，不能在各业务模块内分别修补。

## 决策

1. 所有聊天复用 `ChatComposer` 与显式 `ChatComposerSurface` 状态机。
2. 关闭、系统键盘、表情、附件和语音是互斥输入状态。
3. 聊天宿主关闭 `Scaffold` 的自动键盘压缩，由统一输入区域独占底部占位计算；键盘与自定义面板切换时记录当前键盘高度，自定义面板按键盘收起的高度反向补偿，使两者总占位保持稳定。
4. 自定义面板切回键盘时保留原面板，待系统键盘在同一布局帧接管相同空间后再移除，不产生中间空档；禁止用固定延时猜测系统键盘动画何时结束。
5. 表情面板内部滚动通知不得影响外层 AppBar；顶栏背景、阴影和滚动染色固定。
6. 编辑菜单采用应用级简体中文本地化，iOS 原生菜单与 Flutter 回退菜单保持一致；只保留剪切、复制、粘贴、全选和自定义换行，隐藏查询、网页搜索、分享和实况文本等与聊天编辑无关的入口。
7. 键盘高度必须通过 `MediaQuery.viewInsets` 与页面在同一布局帧读取，禁止通过先于布局更新的系统窗口回调单独驱动面板高度，避免交接最后一帧出现微小位移。
8. 系统键盘高度已经包含 iPhone 底部安全区。自定义面板复用该高度时由输入区域自行负责安全区，外层不得再次叠加 `SafeArea`，否则键盘与面板会产生一个安全区高度的跳变。
9. 若聊天嵌在带底部导航的页面中，输入区域必须扣除已经由宿主占用的底部高度；系统键盘和自定义面板使用同一个扣除值，禁止分别计算两套页面位置。
10. 自定义表情和附件面板只使用输入区域内部的一个动画控制器，以同一底座高度平滑展开和收起；禁止各业务页叠加 `AnimatedSize`、固定延时或第二套面板位移动画。
11. 表情切回系统键盘时，只有当键盘高度与保留底座高度进入亚像素容差后才清除补偿面板，避免交接最后几像素出现下沉再回弹。
12. 无底部导航的独立聊天页必须把设备底部安全区作为输入底座的最小占位；系统键盘收起时使用“当前键盘高度与静止安全区高度的较大值”，禁止先降到零再恢复安全区，从而避免最后一帧下沉后回弹。带底部导航的宿主静止占位仍为零，不改变已验收的广场布局。
13. 未显示自定义面板的稳定状态和完成键盘交接后的状态必须把共享面板动画归零；从稳定空白状态打开表情或附件面板从零进度开始，收起尚未完成时的新指令则从当前可见高度直接接管。禁止让上一次键盘交接遗留的动画终值决定下一次面板是否出现，也禁止为了接管旧动画跳回起点。
14. 自定义面板打开时必须同时检查输入焦点与系统键盘高度：输入框仍有焦点才视为键盘交接；输入框已经失焦时，残留的少量 `viewInsets` 只是系统键盘退场尾帧，必须使用最近一次完整键盘高度并启动自定义面板动画，禁止把尾帧高度误记为面板目标高度。

## 影响

- 输入交互修复会自动覆盖广场和好友，地点与活动接入聊天后直接复用。
- 不改变消息 API、数据库或服务器状态，不需要数据迁移。
- 新输入模式必须扩展状态机和共享输入区域，禁止在业务页面额外拼接独立底部面板。

## 验证

1. 自动测试模拟键盘高度从完整、过渡到关闭，断言自定义面板反向补偿、总占位稳定且输入栏纵坐标不变；反向切回键盘时覆盖最后几像素的逐帧高度。
2. 长按编辑菜单在简体中文环境显示中文操作。
3. 发送表情后面板保持打开，系统键盘不自动回弹。
4. 真机逐帧验收键盘与表情双向切换，顶部颜色不变、页面不跳、最后一条消息完整可见。
5. 自定义面板独立打开和关闭时验证起始帧、中间帧和结束帧，确保不是瞬间出现或消失。
6. 无底部导航的独立聊天页逐帧模拟系统键盘从完整高度收起到零，断言输入栏单向滑回安全区并稳定停靠，不出现末帧反向位移；同时回归带底部导航的广场宿主。
7. 重复执行“键盘—空白—键盘—空白—表情/附件”和“面板收起中再次打开”序列，断言每次请求均经过中间高度并最终显示目标面板，不因历史动画状态出现瞬间跳转或吞点击。
8. 模拟系统键盘失焦后仍残留少量高度的退场尾帧，再分别打开表情和附件面板；断言面板从安全区平滑展开到最近一次完整键盘高度，不出现按钮已选中但面板高度为零。

## 真机验收

2026-08-04 在 iPhone 16 Pro 的 staging Profile 构建完成冷启动验收：系统键盘与表情面板双向切换无尾帧抖动，表情面板打开和关闭使用统一滑动动画，连续发送表情不会唤起系统键盘，最后一条消息、顶栏和底部导航均保持稳定。该结果作为后续广场、地点、活动和好友私聊输入交互的冻结基线。
