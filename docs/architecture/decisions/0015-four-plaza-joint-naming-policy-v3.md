# ADR 0015：四广场联合命名策略 v3

- 状态：已接受
- 日期：2026-08-03
- 补充：ADR 0014 的区域候选策略

## 背景

区域命名策略 v2 已过滤幼儿园、培训机构、办公室和内部楼宇，并能发现三公里内的区域地标。但四个广场仍逐格按顺序挑选候选：先处理的网格可能抢走一个共享地标，迫使真正需要该名称的网格使用较差候选。实际居民更倾向选择中央城市广场、民权站、葡萄酒厂遗址、稳定社区或村庄等区域心智名称，而不是机械选择离网格中心最近的 AOI。

道路还存在另一类风险：长道路横跨多个网格，直接使用同一道路名会降低辨识度；但在没有道路几何和正式分段依据时，自动编造“东段、南段”也可能产生不稳定名称。

## 决策

1. 命名从逐格贪心升级为四格联合分配。每个网格保留有限的高质量候选，通过确定性的有界搜索最大化四格总得分，并禁止同一批四格重复使用同一名称。
2. 候选得分按居民区域认知分层：正式城市广场最高；公共交通枢纽和历史文化、遗址、景区次之；大型稳定商业广场、主体公共服务设施、社区、村庄和商圈依次降级；道路只作最后兜底。
3. 联合分配给予不同语义类别小幅多样性奖励，但不设硬性类别配额。四个高质量公共地标可以同时入选，低质量候选不能只为“凑类别”击败明显更好的地标。
4. 商业候选只接受地图类型确认的大型商场或购物中心；普通商店、超市、银行、酒店和商户名称即使包含“广场”也不得入选。
5. 村庄级和乡镇级地名成为正式兜底层。`赵庄村`规范化为`赵庄广场`，`鲁庄新村`保留为`鲁庄新村广场`；村委会等机构名称仍被过滤。
6. 道路优先使用高德返回的自然交叉口，例如`西郊北路·庄周大道广场`，再退到单一道路名。只有取得可靠道路几何、正式路段或稳定自然边界后，才引入`东段/中段/西段`，当前不得根据一次定位或四格相对位置编造路段。
7. 区域周边搜索改用高德权重排序，距离继续由领域排序器独立扣分，使有限结果页优先包含区域代表性地点而非全部被最近的小 POI 占满。
8. `plaza_grids.naming_kind` 持久化最终语义类别，`naming_policy_version=3` 触发旧自动名称安全重算。广场、会话、消息、未读和锚点身份不变。

实施验收补充：高德可能同时把站前广场、遗址广场标成“城市广场”。策略版本 4 保留城市广场的区域权重，但将名称中明确的车站和文化景观分别记为 `transit`、`culture_scenic`，避免语义类别被地图通用类型覆盖；显示名称和广场身份均不改变。

地铁命名补充：策略版本 5 将地铁站提升到与正式公共广场、城市级地标相同的最高候选层。无论站名来自学校、医院还是社区，展示名都规范为“站名 + 地铁站广场”，例如“市人民医院地铁站广场”，不得退化成学校、医院或社区广场。普通火车站、客运站和机场继续使用交通枢纽层级，避免所有交通设施无差别占据四格。

## 算法边界

- 四格最多各取前十二个候选，最坏搜索空间保持为可预测的小规模，不引入通用优化器或微服务。
- 总分由各候选语义与距离分数加类别多样性小额奖励组成；同分时按固定名称顺序决胜，确保相同地图输入产生相同结果。
- 当前四格中不参与重算的稳定名称作为保留名称，不参与本批分配；全局同名可以存在，因为展示名不是身份键，搜索和会话仍使用广场 ID。
- 任一地图请求失败、无候选或联合分配无结果时保留原名称并按既有退避策略重试，不阻塞位置上下文。

## 验收

1. 共享地标分给替代候选最弱的网格，四格总质量优于逐格贪心结果；
2. 中央城市广场、民权站、葡萄酒厂遗址、圣晖广场、华联城广场、南华社区和绿洲社区均进入正确语义类别；
3. 赵庄村、鲁庄新村能生成稳定村庄名，村委会不能入选；
4. 道路交叉口优先于单一道路，社区和村庄优先于道路；
5. 策略 v3 重算后四个名称不同，`naming_kind` 和策略版本可审计，广场与会话身份不变；
6. Node、数据库迁移、Flutter CI 和 staging 四格真实高德验收通过。
